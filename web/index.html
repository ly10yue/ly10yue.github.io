手感设置与玩法说明

点击需要落在开放区域内，横向对准音符；高度不限。Hold 按住并跟随它与底部判定线的交点。电脑可以使用鼠标，或 D / F / J / K 四个键。

iPad 推荐横屏 Safari，可通过“分享 → 添加到主屏幕”打开。音频会在点击开始后启动；切后台或旋转屏幕会自动暂停。暂停后继续有 3 秒倒数，可提前重新按住 Hold。

支持 0.11.0 与 0.12.0 谱面（v3–v6），单包不超过 64 MB、歌曲不超过 10 分钟。浏览器可能清理本地存储，请保留原谱面文件。
